1. tiny buffers                               *tiny-buffers.nvim-tiny-buffers*

Currently this module adds only one commands `Bc` to close a buffer but keep
the window.


SETUP                                   *tiny-buffers.nvim-tiny-buffers-setup*

Setup with lazy

>lua
    return {
        'coding4glory/tiny-buffers.nvim',
        opts = {}
    }
<


CONFIGURATION                   *tiny-buffers.nvim-tiny-buffers-configuration*

There is only one optional setting `try_keep_open` which tries to always keep
an open editor buffer. This setting is **experimental** and might cause annoing
behaviour in combination with windows opened to the side e. g. _file trees_.


USAGE                                   *tiny-buffers.nvim-tiny-buffers-usage*

Simply `:Bc` in normal mode.
